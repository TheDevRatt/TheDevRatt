## hey, i'm matthew

I'm a full-stack developer who likes building things that feel good to use and aren't painful to maintain. Most of my work sits somewhere around C#/.NET, TypeScript, web apps, Discord tooling, and Godot experiments.

I graduated from Trent University with a B.Sc. in Computer Science, a 3.9 GPA, Dean's List standing, and Academic Honours. Right now I'm looking for full-stack or systems-adjacent software roles where I can ship real product, learn fast, and keep getting sharper.

- Full-stack web apps with C#, ASP.NET, SQL Server, TypeScript, React, and Angular
- Game tooling and Godot experiments, especially when C# gets involved

- Mobile and cross-platform apps with React Native
